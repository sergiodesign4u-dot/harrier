Molecule

Miss

The column that says an address resolved to nothing. 1 instance on 1 screen, node 8.1.

It carries one rule that is not small. In a multi tenant security console, “no such case” and “not your tenant” must render identically, or the address bar becomes a way to enumerate another provider’s clients. Everything about this component follows from that: it names two exits and it names no cause.

Not a dead end, and the name says so. CLAUDE.md requires that none of the systemic states be one, and this screen answers that with exits. It is called miss because the address missed, which is a fact about the request rather than a verdict about the person reading it.

It is the fourth systemic screen and the first one the system could not dress. Node 8.2 has outage, one molecule with a heading and four zones, built because it had three coloured renderings. This node had one, in grey, so the census filed its five classes as one-offs and “one use is not a role” kept them out. Correctly, from evidence that was complete and unrepresentative, which is the same shape as contact.is-gone two rows above it in the enrichment journal.

The address itself is addr, and this screen is the instance that file has been naming since stage 08. Its header said “the sixth is node 8.1’s nf-addr, which the inventory explicitly keeps out of the kit”. Declaration for declaration it was the same component under another name, so nothing was built for it: addr’s count went from 5 to 6, and it stopped being node 5.4’s alone.

Behaviour on width

A container query, and the rung below it was tried first. The grey wrote this step as a viewport query at 900, a number stage 10 deleted from the product. Fluid cannot do it: the step runs the wrong way round, larger as the column gets narrower, and a clamp whose middle term is vw can only run the other way. So it is the container rung, at 30rem, registered in responsive.md section 6 with the rest.

This is the one place in the product where something gets bigger on a phone, and the reason is a tap target rather than a reading size. The page is reachable from a pager at 03:00, which makes 360 a real width here rather than a proof.

And the measure is on the text as well as on the column. The first version of this component put --measure only on the column, which is the mistake base.css warns about by name: a measure is counted in characters, and text at two sizes in one column stops at two different pixel widths. The column is 66ch of 15px type and the notes are 11px, so they ran 81 characters at 480 and 89 at 520. The width sweep reported it at 42 widths, and it is the same finding stage 10 recorded at the same width: the longest line in this product is not at 2560, it is at 520, because below the point the layout is one column and the smallest text in the product fills it.

Variants

AxisValueUsesThe rule
causeno values–Prohibited, and it is the whole component. There is no --denied and there will not be one. Never existed, outside your scope and not yours to open must be one drawing, because the difference between them is the leak
emphasisno values–Prohibited. No accent, no mark, no ground. Arriving here is not an error the analyst made, and a page that dresses itself up as an alarm makes a mistyped id feel like a security event
exitsno values–Two is a count, not an axis, and it is the count the block bank fixed: the queue if it is open, the log if it was closed

When to use it

Once, on node 8.1, at any address that does not resolve. It renders inside the shell when the reader is authenticated and standalone when they are not, and it looks the same either way, which is the same rule again seen from the other side.

Where she meets it. After pasting a case id from a ticket, from a channel, or off a phone call at 03:00. She is not lost, she has one wrong string, and the two things she needs are the string back and somewhere to go.

Rule and anti-rule

Do

A case id that did not resolve here is still worth two looks. Open the queue if the case is still open, or Open the log if it was ruled on and closed.

The exits are text in a sentence. The sentence says which exit answers which question, so choosing between them costs no thought.

Do not

Open the queue Open the log

Never a button pair. It makes one of the two look like the right answer when the right answer depends on something only the reader knows, and the block bank ruled it out for this page type by name.

Limits

  • R1one main action per layer, and this page has none: the exits are links and the only btn on it copies the address. Nothing here is primary, because nothing here is the thing to do
  • R5it renders with the shell and without it, and the component may not know which. Anything that depends on being signed in belongs to the shell, not to this column
  • addrthe address goes in addr, never in a bare code. It is a string somebody pastes into a ticket, so it gets a boundary, a ground and a button

States

It has none, and it is not interactive. The controls inside it are two links in the sentence and one button beside the address, and each carries its own. The column is read.
