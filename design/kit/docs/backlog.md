# Backlog

What the reconciliation at stage 08 step 6 decided **not** to do, with the reason and the stage that closes it. One row per item, and every row names who closes it: an entry with no owner is a wish rather than a backlog item.

This file exists because the alternative is silence. A thing that was found, considered and deferred looks exactly like a thing nobody noticed, and the difference is the whole value of having looked.
