Colour is not the only carrier. That is the reason the glyph is banked from the Defender incident row, and it is what stage 06 will need when colour arrives.

Severity is not the action class. 0.6 orders its ladder by reversibility and says so in its own words: isolating a production server is severe and cheap to undo. Two axes, and they are allowed to disagree about the same case.

Open, and it is a real product question: an MDR provider ingests severity from many source tools with incompatible scales. How a source scale maps onto these three is [?] and belongs to whoever owns ingestion.

03 · Time, two grammars because there are two questions

She decides on elapsed. She defends on absolute

Time grammarthree forms, one per question
HOW LONG HAS THIS BEEN TRUE
27m · 4h · 3d

Bare unit, no ago. Queue rows, freshness, the age of a case, the annunciator window

WHEN EXACTLY DID THIS HAPPEN
2026-08-21T04:12:38Z

ISO 8601 in UTC. 5.1, 5.4, the snapshot, anything that leaves the product

WHICH SHIFT
19:00 to 07:00

Wall clock, and the surface names the zone. 2.1 only

  1. Bare unit in a column, ago only in a sentence. Repeated down forty rows it carries nothing and costs the width of a word forty times. Prose keeps its preposition.
  2. One unit, never two. 1h 20m is two numbers where the glance can take one. Precision that changes no decision is not precision.
  3. An absolute time never appears alone on a working surface, and an elapsed time never appears alone in the log. 4.1 carries both, because it is the one surface that does both jobs.
  4. UTC in the log, and it is not a preference. One analyst covers tenants across the United States and the EU, so a local rendering in an append only record makes two entries incomparable at the exact moment someone is comparing them.

Retired at this node, with where each one goes: Meridian Freight to Halden Freight, Cadence Retail to Bramber Retail, Northwind to Norsk Marine, Vestry Capital to Meridian Health, Ashgrove Legal to Aubrey Dental Group. Five names, none of which carried a role another was not already carrying.

One canonical case: C-4417, at Larkfield Logistics. Every node that draws a case draws this one, and it shows the same severity, the same signal count and the same verdict on 3.1, 4.1, 4.2 and 5.4.

The id carries no meaning, and that is a decision rather than laziness. An id that encoded the tenant or the date would leak across tenant isolation the moment a link is pasted into a channel someone else can read, and it would defeat 8.1, which requires that not found and not yours are indistinguishable. It is short because it gets read aloud on a phone at 03:00.

Numbers in a wireframe are fixtures, not findings. They are sample content, chosen to make a layout decidable, and none of them is a measurement. No fixture may be quoted anywhere as evidence about the market, about analysts, or about this product’s performance. What they must be is internally consistent: the same case, the same tenant and the same count read the same on every surface that shows them.

This is the rule the project already runs on written claims, applied to the drawings, because the drawings are what stage 07 puts in colour and colour is what people believe.

06b · No state matrix, and that is the answer rather than an omission

0.6 and 0.7 both carry one. This node renders nowhere, so a matrix here would be other nodes’ states copied into a third place

0.6 renders as the grant grid, 0.7 as the option list inside 4.4. 0.8 has no surface of its own, no route and no states, and every value in it is drawn by a node that has its own matrix. What replaces it is the table in 06 naming which nodes read which convention, because a second copy is the one that goes stale.

The one thing here that behaves like a state is the tenant with too few rulings to compare, and that belongs to 3.5, which owns it and renders it.
