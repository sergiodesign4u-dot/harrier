The fleet gets no item of its own. It is the resting state of the Queue’s right pane, so it costs zero taps. A menu item would turn it into a place you have to go, and the point is that looking at it should not be a trip. The price, named: the way back is a deselection rather than a navigation, which is a discoverability risk. If the empty state of the pane does not read as "this is the fleet" rather than "this is empty", the decision fails, and stage 04 inherits that explicitly.

PathTaps
B1 Queue (landing) → select a case → file the verdict2
A1 Shift brief (landing) → a pointer into the case → file the verdict2

The second number is the interesting one, because it does not rest on trimming a menu. It rests on a property of the object: the handoff is signposting into cases rather than a document, which four of six interviewed responders described, so its pointers lead straight into a case. Had the handoff stayed the prose document the original stage 01 decision described, this path would be three taps, because a step would appear: find that case in the queue.

What flattening cost. The fleet has no menu item, so it is less discoverable. The secondary persona’s action sits at level 3. The client summary is far from the case it grows out of.

Global, contextual, deep. Global: the four items, plus the tenant’s autonomy state in a fixed position, which is a requirement taken from the Flight Mode Annunciator rather than a preference, because a mode that has to be inferred is a display failure. Contextual: C1 in the pane, the rejection reason inline on C1, E1 from a case or a client. Deep: changing a grant on F1, the log narrowed to one case.

Estimate: five screens in the MVP, three later. Stages 03b, 04 and 07 all start from the MVP subset rather than from the whole map.

Orphans

None in either direction. Every column carries a tick and every row carries a tick. Reported rather than celebrated: a check that returns zero proves nothing about itself, so the matrix was pushed harder, and it gave up two findings a tick count alone would have hidden.

What the matrix found instead

Two of six jobs cannot close inside the MVP. R4 carries ticks only on an entry point and on two LATER screens, so it is genuinely deferred. P2-MAIN carries its read on B2, which is MVP, and its act on F1, which is LATER, so only half of it is buildable in the first round.

B2 Fleet sits on the primary persona’s landing screen and serves no job of hers. Its only tick comes from P2-MAIN, which belongs to the secondary. The explanation sharpens the bet rather than excusing it: HJ1, "when I start a shift, I want to know where the agent has earned latitude and where it has not", is assigned to P1, but it lives in the hypotheses section and this matrix carries only functional jobs, so the link was invisible. The fleet on the primary’s landing screen rests on an unverified hypothesis, which is what stage 04 has to make readable and what a first test would have to kill.

And the second one goes straight at the MVP core. P2-MAIN is one of the three core jobs, entered as the bet. The matrix shows the bet is narrower than it read at stage 02: it is not that an analyst will change latitude from the console, it is that seeing where latitude stands changes the decisions they make on cases. That is a sharper statement of H1, and it came from counting cells rather than from thinking harder.

Two checks that were made and are recorded here rather than beside the schema

Against the chosen UX pattern, and one conflict was found. C1 as its own full-page route breaks the reason that cheap override needs the list to survive the decision. The map was corrected rather than the pattern: C1 has two renderings of one screen, the detail pane inside the console and a standalone route for a permalink and for mobile. The console never leaves the split.

Against the entity inventory, and one finding came back. Signal is the only object with no screen where it is the subject, which is a product decision rather than an omission. The pass was built to hit that consciously instead of letting it slide.
