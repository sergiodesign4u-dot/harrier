# Harrier

Adjudication console for analysts at managed detection and response providers. One analyst covers 40 or more client tenants. An AI agent called Clerk assembles cases and files a draft verdict; the human rules on it.

Built as a design engineering case study. Rules of the project live in `CLAUDE.md`, the decision log lives in `docs/decisions.md`.

Live: https://sergiodesign4u-dot.github.io/harrier/
